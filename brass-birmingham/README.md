# 工业革命：伯明翰 · 夜间对战测试版

独立实现的无构建静态网页，部署目标为 GitHub Pages。使用已下载的夜间棋盘、卡牌、四色产业板块和夜间玩家面板。

0.2 桌面布局：主地图扩大，49个产业槽位根据当前夜图单独测量。三处牌堆区域展示抽牌堆、万能地点牌与万能产业牌；市场资源、商人板块及啤酒按原图位置展示。完整夜间玩家面板含29种产业等级和开局45枚实际堆叠板块，可查看各玩家的公开产业库存，建造或研发后实时减少。

运行：`npm run serve`，打开 http://127.0.0.1:8765 。测试：`npm test`。

支持2–4人、本地规则AI、房主权威的 WebRTC 联机、合法行动校验、资源来源选择、多产业出售、双铁路、侦察、欠款变卖、两时代计分，以及本地自动存档和导出。

AI 为确定性的启发式规则策略，仅评估公开棋盘及自身手牌，不读取牌库顺序或其他玩家手牌。没有训练模型或外部模型API。

联机流程：创建房间，分享8位房间码或邀请链接；朋友加入后房主开始，空位自动由AI补齐。客人断线可在原标签页从菜单重连。刷新后再次用原房间码加入也会恢复座位。房主必须保持在线；房主存档恢复后变为本地AI对局，不声称恢复旧联机房间。信令依赖公共 PeerJS 服务，严格 NAT / 防火墙可能无法直连。

`public/engine.js` 是纯规则状态转换；`facts.json` 是实体游戏参数；`ai.js` 是启发式决策；`room.js` 管理传输与座位；`app.js` 提供中文交互。资源先在副本中结算，资源选择中断或非法行动不会部分扣费；联机行动携带局面版本，由房主绑定座位执行，拒绝越权和过期行动。客人收到的视图没有其他玩家手牌、牌库、洗牌种子和初始暗弃牌。

属于规则与联网测试版，未作竞技级规则认证；原版游戏、美术与第三方组件的来源和权利说明见 `public/NOTICE.txt`。

0.3 配件：沿印刷线路摆放实体运河/铁路板块，面板下展示剩余14枚连接板块及实际现金金币；左下头像按行动顺序排列并叠放本轮花费金币；四色VP与收入标记在100格外环定位，超过100分显示圈数。39条线路和100格轨道分别校准。

0.4 操作流程：手牌改为可收起的悬浮框；先选行动，再点地图/面板高亮目标，最后选弃牌。建造汇总全部手牌支持的位置，研发直接点最低级板块，双铁路逐条点选，销售直接选产业与商人，再点击啤酒来源。选择阶段不修改局面，提交时仍由规则引擎原子校验。
