1. 游戏目标与全局框架

先了解何时获胜、敌友关系，以及一季的四阶段。

你将扮演董卓、袁绍、曹操或孙坚，通过经营地区、招募人才与战斗争取威望。

1.1 胜利与时限

游戏从190年春开始，每轮为一季，依次经过春、夏、秋、冬，最多进行到192年冬，共12季。

每季全体玩家完成朝会、朝贡和锦囊限额结算后，检查胜利：任一玩家达到16威望，或在群雄逐鹿时期拥有至少7个地区（含关隘），即可结束游戏。若触发7地区条件，仅比较达到7地区或16威望的玩家；否则按原规则比较全体。最迟192年冬结束。先结算终局锦囊，再比较威望。平手依次比较：是否控制洛阳、拥有地区数、普通士兵总数、金与粮总和；仍同分则共同获胜。中途达标不立即结束游戏。

3.2 地区、军团与冲突

地区所有权与驻军独立记录。友军共处、撤空守军、移动进入或时期转换，均不自动改变所有权。

同一势力在同一地区的全部普通士兵组成1支军团；敌对军团共处时，该地区为冲突地区。冲突本身不限制内政、兵力部署、任命太守或太守效果。

地区包含城市、大城和关隘；效果写“城市”时包含大城，不含关隘。牌面写“己方地区”按所有权判断，不按驻军判断。兵牌不是普通士兵，不增加兵数、行军耗粮或战损人数，也不能独立维持军团或参加斗将。

3.4 打出、回收与移除

人物牌有内政、军事、朝会三栏。从手牌打出时只结算当前阶段的一栏，牌放入打出区。当前阶段必须有合法用途：

  • 内政：至少有1项能实际执行的内政行动。
  • 军事：【武】有军令、战力或可生效军事效果；【文】可部署以增加锦囊限额；【兵】有合法部署军团且军事栏有用途。
  • 朝会：该栏有收益，且当前满足条件、能支付代价。

“弃置”将牌放回所属玩家弃牌区；“移除卡牌”将牌放入公共移出游戏区。自由选择己方人物来任命或移除时，可选手牌、打出区、弃牌区；指定某张牌、敌方牌或失地太守的效果按指定对象处理。

回到手牌的人物可依当前阶段规则再次打出，但不重置每季／每局次数。卡牌发动的回手效果不能选择发动牌自身，其他同名实体牌可选。通用朝会回收不受此限制。

部署标记与实体人物牌一一对应。同名牌必须能区分；取回或移除来源牌时，清除它的配对部署标记。战斗退场与强制召回的区别见7.2。

3.5 地区特色的使用

每个地区、全体势力合计，每季只有1次特色机会。

城市本季第1次内政行动后即耗用特色机会；只有行动类型匹配时才取得加成，后来其他玩家也不能再用。文官太守的强化共用同一次机会。关隘则在本季第1场战斗中提供防守+2，战后耗用；关隘执行内政不消耗这项防御机会。

除中立地区议事恢复外，繁荣不自动恢复。已执行内政、特色已耗用及关隘已交战均需记录。

3.6 信息与裁定

公开：资源与标记、地区状态、部署人物及来源、各牌堆数量、人物手牌和锦囊数量、打出区／弃牌区／太守区内容、公开人物及投资、顺位、联盟目标、技能使用和本季行动记录。

隐藏：他人手牌内容、牌库顺序、未公开的战斗锦囊与军令提交。除牌面允许外不能查看。自己的手牌可随时查看；锦囊使用后面朝下放入公共锦囊弃牌堆，牌库抽空时洗混该堆。

明确的“不能、无视、改为”效果优先，其次地区与太守效果，最后通用规则。同一时点先由行动玩家处理自己的效果，再按本季顺位处理其他势力。除法未注明时向下取整；募兵例外向上取整。

4. 议事阶段

全体先结算太守收入，再处理标记和补牌，最后设定联盟目标。

每季依次执行：

  1. 更新政局：若上季登记联军解散，进入群雄逐鹿时期；双人局先完成联军分裂（附录D）。
  2. 季度准备：核对持续效果，重置每季次数、地区特色和地区战斗次数，洗混剩余锦囊牌库；各中立地区繁荣+1，不超过上限。
  3. 地区兜底（仅四人）：拥有地区少于2个的玩家，可接管1个属于自己初始地域的普通中立地区，将其全部士兵变为己方士兵。每人每季至多1次，可放弃。初始地域为董卓关陇、袁绍河北、曹操中原、孙坚楚地。
  4. 太守收入：按顺位结算全部太守区收入（10.2），同一玩家自行排列太守顺序；其间获得的治民或起义标记当季可用。全体收入完成后才补牌。
  5. 补牌：每人通常补手牌至5张，再处理至多1枚治民或起义标记。治民：移除1枚，额外抽1张，即使原手牌已满也可用。起义：本次少抽1张；只有原本能抽牌时才移除，否则保留。
  6. 联盟目标：讨董联军时期，袁绍可指定1个董卓控制地区为本季目标，也可不设（11.2）。议事阶段不打出人物。
补牌例：手牌3张且有2枚起义标记，原应抽2张；移除1枚起义标记，只抽1张，另1枚保留。手牌5张且有治民标记，仍可移除1枚并抽1张。

5. 内政阶段

每次选择人物、行动与地区，完整结算一次，再轮到下一位。

5.1 行动步骤与进入条件

从首位起轮流行动。每次打出1张人物，选择其列出的1项内政行动和1个地区，完成全部效果后结束本次行动；也可PASS，退出本阶段。所有人PASS后进入军事。

  2. 支付影响费，开始行动，处理行动前效果；搜寻、刷新等附带选择不另收影响费。
  3. 计算强度，选择实际数量，支付并结算内政行动。
  4. 先结算地区特色，再结算人物的行动后效果；明确写在行动前或其他时机的效果按牌面处理，完成全部选择。

5.3 内政锦囊与恢复

每次内政行动可使用1张相应锦囊，依附录C所列窗口结算。【人脉】可在自己的内政行动回合独立发动，不必执行招贤。

恢复繁荣可通过巡查、贸易、人物或锦囊效果完成。友军／敌军在场不妨碍恢复；正常内政的进入条件仍适用。

6. 招贤、搜寻与展示区

先放自动点数，再处理搜寻或刷新，最后自由分配招募点。

6.1 一次招贤的顺序
  1. 先放自动点数：开始招贤时，向当时展示区所有与行动地区同地域的人物各放己方1点；曹操【求贤令】再向当时全部展示人物各放1点。两者可叠加。
  2. 处理人物附带的搜寻或可选刷新。自动点数先于这些效果；本次新补出的牌不补放自动点数。
  3. 获得行动强度对应的招募点，可自由分配至任意公开人物，也可每支付2点访贤、抽1张锦囊。
  4. 任何人物上的己方点数达到招募费用，立即招募。继续分配剩余点数；行动结束未用点数失去。

地域只影响自动点数，不限制投资和招募。通常招募所得人物：讨董联军时期放入个人弃牌区，群雄逐鹿时期放到个人牌库顶；牌面另有说明时按牌面。招贤以外获得的招募点也立即使用，但不触发地区或求贤令的开始奖励；未指定用途的点数可投资或访贤。

6.2 人物离场与投资奖励

公开人物被招募或弃置时，检查该牌上的所有投资：

  • 每名投入至少3点的玩家，各获得1次该人物太守栏的收入；“无”不奖励。这不是任命太守。
  • 常规位离场即补足3张，随后结算奖励，最后清空该牌投资。【名】奖励的3点只能投资公开人物，不能访贤。
  • 弃置公开人物时，若有唯一最高投资者，由其取得人物并放入个人弃牌区；并列最高或无人投资则放入公共人物弃牌区。刷新除外，见6.4。

常规人物最多3张。人才库抽空时，洗混公共人物弃牌区继续抽取；无牌可抽时才不足3张。

6.3 搜寻：临时第4位

按指定标签（地域、文／武／兵或太守简称）翻开人才库，直到找到符合者；【人脉】也可指定费用。未选中的牌弃置；将找到的人物放入临时第4位。

已有搜寻人物时，先按6.2弃置旧牌，新牌替换它。搜寻人物被招募或弃置后不补位；因此展示区最多4张。无符合人物则搜寻无结果。

搜寻不收独立费用，也不额外提供招募点；具体牌面给予的点数照常结算。

6.4 刷新与清流议士

刷新把3张常规人物放入公共人物弃牌区，不能按最高投资取得；但仍给予所有至少3点投资者离场奖励，然后补足3张。临时搜寻位不受影响。

清流议士在招贤行动中可刷新1次：自动点数放完后即可选择，也可先投入部分点数再刷新。执行贸易时，则在行动前刷新。

7. 军事阶段

打牌和花军令可以分开选择；兵牌不占文／武出牌额度。

7.1 每次行动

从首位起轮流行动。每次可打出至多1张【文】或【武】，并使用已有军令行军或进攻；不必为了使用军令而打牌。兵牌不占这1张额度，可单独打出，也可打出多张。

只要打出人物或消耗军令，就算一次行动；两者都不做则PASS。已PASS者退出本阶段，剩余军令弃掉，但仍能防守、紧急部署并使用由此获得的军令，不重新加入主动行动。无手牌且无军令时自动PASS。所有玩家PASS后结束军事。

军事人物打出即取得牌面军令；军令跨本阶段行动保留，战斗结束不清空。紧急部署也提供军令。

7.2 部署与容量

打出军事人物时，可普通打出，或将其部署到1支己方军团，放置与来源牌配对的标记。部署失败不放标记，卡牌仍进打出区，能结算的效果照常结算。

同季不能主动替换已部署人物。合军导致文／武超出容量时，选择超额人物强制召回。普通士兵减少或合军后兵牌超额时，选择多余兵牌清除部署标记，来源牌留在打出区。普通打出但未部署的人物不能在之后补部署。

战斗退场只清除标记，人物留在打出区；强制召回清除标记，并将人物从打出区弃置。均不退还已取得或花费的军令。军团无兵时不能维持部署；战后无兵清除全部标记、来源牌留在打出区。

7.3 行军
  1. 选择1支己方军团、相邻目的地及移动兵数。通常每步支付1军令＋每移动兵1粮；从敌方地区移向敌方地区时改付2军令。
  2. 移动全部或部分普通士兵。拆分时选择每张部署牌随哪支军团，两边均须有兵且不超容量；合军后按7.2处理容量。
  3. 跨河不付金，但立即停止本次行动，获得渡河标记；在该玩家下一次正常军事行动开始时移除。防守响应不算下一次正常行动。
  4. 进入有敌军的地区停止继续移动。可依法发起进攻；一旦完成1场进攻，本次行动结束。

免费调兵免军令、粮与金，仍须相邻、符合容量，并遵守渡河等移动限制。牌面允许直接部署募得士兵到邻地时，按牌面处理。

7.4 发动进攻

支付1军令，在己方军团所在地区选择1支敌方军团，按第8章战斗。每地区每季至多2场战斗；同一行动不能在同一地区连续发起两场。

若地区属敌方且无敌对驻军，可支付1军令进攻空城，直接取得所有权，不进入战斗，不耗战斗次数，不给战功或战败锦囊补偿。移动进来本身不会自动占领。

8. 战斗

按六步结算战斗；战损、战功与地区易主分别判断。

8.1 六步结算
  1. 指定敌军：进攻方选1支防守军团；同地区其他军团不协战、不承受战损。
  2. 紧急部署：若防守军团没有任何部署标记，可从手牌部署至多1张文／武，以及至多等于普通士兵数的兵牌；也可只部署兵牌。正常部署规则适用，不消耗之后主动打牌额度。已PASS者也可响应。
  3. 秘密提交：双方各选择合法锦囊、主动技能及投入军令。通常各可用1张战斗锦囊，每部署1张文另加1张；主公技能不占限额。每投入1军令，战力+1，立即支付且不能重复使用。
  4. 同时公开：先判断克制，再依次处理有效【疑阵】、【斗将】及其他修正。郭嘉的例外按牌面：先看敌方提交的锦囊和军令，再提交己方。
  5. 比较战力与战损：依8.2—8.3结算。处理伤亡增减、撤退及部署超额。
  6. 结算结果：胜败效果、战功、战败补偿与地区易主（8.4），随后结束本次进攻行动。

战斗预测只展示公开信息，不含未揭示锦囊、军令与技能选择。双方提交期间，不得依据对方未公开内容改选。

8.2 战力

总战力＝参战普通士兵数×3＋部署人物＋地形／太守／主公／锦囊＋投入军令－减益。

只计算本场目标军团。关隘首次防守加成见3.5；太守范围见10.3。两项通用减益：

  • 渡河：-5。军团有渡河标记时适用。
  • 断粮：-5。在己方地区不算断粮；否则须相邻至少1个己方、友军或友好中立控制地区才能免除，连接地区处于冲突也有效。仅有己方驻军、但所有权敌对的地区不提供补给。

两项可叠加。鲁肃免疫适用的战力减益，包括断粮、渡河与火攻；不阻止斗将退场，也不改变伤亡。

8.4 战功、补偿与易主
  • 战功：仅实际胜方，按败方本场阵亡普通士兵数取得，受时期对象及每季2／3上限约束（1.2）。平局、败方、空城与夺城本身不获战功。
  • 战败补偿：实际败方玩家抽1张锦囊；中立军团不抽，平局也不抽。
  • 取得所有权：防守方是原地区所有者、进攻方获胜后仍有兵，且地区已无其他敌对军团，才取得该地区。双方都无兵时不易主。
  • 群雄逐鹿时期：夺取城市或大城获得1枚起义标记，关隘不产生此标记。
  • 失地：不扣金粮、不加起义；失去太守标记按10.4处理。

祖茂的“视为胜利”只触发胜利类效果（含孙坚连胜），不改变实际胜负、伤亡、战功、战败补偿或所有权。

8.5 三角克制与斗将

三角关系：疑阵克伏击，伏击克斗将，斗将克疑阵。被克制锦囊无效；同名锦囊均正常结算；火攻不参与克制。完整锦囊见附录C。

锦囊强化：军团部署的任一人物有【某锦囊】强化时，己方该锦囊忽略其牌面使用条件，不会被三角克制。锦囊生效后己方战力+1，同名强化不叠加。【斗将】强化例外：不另加战力，只有选为出战者的强化武将多掷1颗骰子。强化不会突破战斗锦囊限额、封锁或人物直接使锦囊失效的效果。

普通【火攻】要求敌方至少3名普通士兵；其余三张无额外条件。通用窗口、封锁和使用限额仍适用。【疑阵】先结算：敌方1名普通士兵沿合法退路撤离，不计战损；无路可退时留在原地，本场不参战且不承受战损。鲁肃仍可免疫疑阵。

有效【斗将】的使用方先获本场战力+1。双方各选1名参战【武】人物，按牌面战力掷等量骰（0／0／1／1／2／2★），若所选武将有【斗将】强化则多掷1颗，由当前行动玩家一次掷出双方骰子。2★也计2点。比较总点数，平局无胜方；只有一方有武将时该方自动获胜，无须掷骰；双方都无武将则无胜方。胜方若使用了有效【斗将】，本场额外+3。仅当胜方的2★严格多于败方，才撤下败将部署标记，人物牌留在打出区。双方均使用也只决斗1次，不追加军令或扣除败将牌面军令。

8.6 诈降士兵

将1名普通士兵横置，仍属原势力并计入兵数。其军团战斗开始、选择锦囊前，把本地区己方诈降士兵恢复普通士兵：本场己方锦囊不受三角克制，且造成的最终战力修正翻倍；多名不叠加。

诈降不改变使用窗口、限额或费用。【疑阵】仍只处理1名普通士兵，不额外迫使另一名士兵或兵牌退场；诈降强化另使该敌军战力-3。诈降士兵离开地区或地区不再冲突时，亦恢复普通士兵。

9. 朝会阶段

全体先回收，再逐人完成打牌、结算、任命与出价。

9.1 全体先回收人物

在任何个人朝会前，按顺位，每人可从自己的打出区或太守区回收1张人物到手牌；可放弃，机会不累积。回收部署人物清除配对标记；回收太守牌同时撤下1枚己方同文／武标记，多个可选。

回收不撤销已结算行动，不重置次数。所有人完成后，才从首位起依次进行个人朝会。

9.2 一次个人朝会

轮到自己时连续完成，结束后不再重新进入：

  1. 逐张打牌：每张先检查当前条件与代价，立即结算，然后可继续。前一张牌可以使后一张满足条件；可保留不打。按窗口使用朝会锦囊和主公技能。
  2. 战功转化：全部战功按1:1转威望并清空；非董卓玩家每转化1战功，迁都进度+1（11.4）。
  3. 任命太守：新跨过4／8／12威望各获1次机会，使用任意已存机会任命（第10章）。
  4. 完成个人结算：可弃置任意人物手牌。董卓检查焚城迁都；袁绍结算本季联盟目标（第11章）。
  5. 朝贡出价：公开出价1次，之后轮到下一名玩家。
9.3 朝贡

每人仅1次机会：选0表示不出价，或出1—9金且高于当前最高价。出价不得超出可用金。立即锁定等额金，不能支付其他费用；被超过时解锁，不能重新竞价。

全员结束个人朝会后，最终最高者支付出价，获得下季首位标记。无人出价则原首位保留，座次不变。最高价至少6金时，获胜者额外获得1威望；汉天子所在地区控制者另得1威望，两项独立。

此时跨过的太守里程碑照常获得机会，留待之后使用，不重开个人朝会。

9.4 季末检查与清场

全员个人朝会完成后，依次：

  1. 结算朝贡与汉天子收益。
  2. 吕布主公弃置全部锦囊；其他玩家锦囊超过5张时弃至5张。平时可以超过5张。
  3. 检查16威望、群雄逐鹿7地区或192年冬时限；若结束，结算终局锦囊、依1.1排名。
  4. 若继续，结算季末指定移除效果，清除全部军团部署，将打出区剩余人物放入个人弃牌区；冲突地区也不保留部署。
  5. 保留太守牌、未打出手牌和持续资源；清除本季临时状态，推进季度。明确写有持续期限的特殊效果按牌面期限处理。

10. 太守

牌在太守区，地图只放文／武标记；收入与地区基础效果分别结算。

10.1 机会与任命

首次达到或跨过4／8／12威望，各获得1次任命机会，永久勾选；威望下降不撤销，也不重复发放。机会可保留，部分牌也可给予机会。

个人朝会战功转化后、朝贡前，每花1次机会，从手牌、打出区或弃牌区选择1张可任命的文／武人物放入太守区，在己方1个无太守地区放相应文／武标记。冲突地区与关隘均可；每地区至多1枚。兵牌、特殊人物和太守栏为“无”的人物不可任命。

任命不算打出，不触发人物三栏。人物牌不绑定具体地点，地区只记录太守类别。

10.4 失地、回收与迁移

失去有太守的地区时，清除地区标记，并由失地方从太守区选择1张相同文／武牌移出游戏；机会不返还。

回收太守牌时选择撤下1枚己方相同文／武标记；移除该实体牌有配对的部署标记时一并清除。

州郡治中可在己方领地内迁移任意1枚己方太守标记至另一己方无太守地区，类别不变；冲突地区与关隘均可。只移标记，不换卡牌。

汉天子随所在地区所有权转移。全体朝贡结束时，控制者获得1威望；与朝贡获胜的收益独立。

11.4 迁都与洛阳

非董卓玩家在个人朝会将战功转为威望时，每转化1战功，迁都进度+1。人物牌的特殊推进按牌面结算。迁都进度范围为0—10。

董卓可用【掌控朝政】增加1进度；进度已满不能发动。双人局若迁都机会仍在，全体朝会结束时自然增加1进度，并再次检查焚城条件。

在董卓个人朝会结算时，若进度至少10、仍控制洛阳且焚城机会未失去，无论洛阳是否冲突，焚毁洛阳并执行：

  1. 董卓失去1威望。
  2. 汉天子移到长安。
  3. 洛阳当前繁荣与上限永久变为1；仍保留原抽牌特色及文太守强化。
  4. 登记联军解散，下季议事进入群雄逐鹿。
